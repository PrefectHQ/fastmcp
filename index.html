About the data

Recorded counts began October 16, 2026, from the existing half-hourly backlog collector. Earlier counts are reconstructed from creation and latest closure dates; they cannot recover periods when an item was closed and later reopened.

Activity comes from GitHub’s public issue and PR records, not changes in the total. Issue outcomes use the reason attached to the latest closure: completed, not planned, or unspecified. “Completed” is GitHub’s closure category, not a claim that a fix shipped. PRs distinguish merged from closed without merging. Historical draft state is not reconstructed.

Snapshots are scheduled every 30 minutes and may be delayed by GitHub Actions. The page checks for fresh data every five minutes. Recent work details cover the last 30 days.
