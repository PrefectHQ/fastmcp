# FastMCP skills

These skills are for agents using FastMCP in their own projects. Install one with
`npx skills add PrefectHQ/fastmcp --skill <name>` or copy its directory into your
agent's skills location.

- [Server authoring](fastmcp-server/SKILL.md): build, extend, and test Python MCP
  servers using documentation matched to the project's FastMCP version.
- [Client CLI](fastmcp-client-cli/SKILL.md): discover and call existing servers.

See [Coding Agents](https://gofastmcp.com/getting-started/ai-assisted-development)
for setup and documentation access. Repository maintenance skills live separately
in `.agents/skills/`.
