# Contributing to FastMCP

Read the [contributing guide](docs/development/contributing.mdx) for accepted contributions, issue assignment, development setup, tests, and review expectations. The same guide is [published on gofastmcp.com](https://gofastmcp.com/development/contributing).

Agents should also read [AGENTS.md](AGENTS.md) and use the repository skills it lists. Report vulnerabilities privately through [SECURITY.md](SECURITY.md). Participation follows our [Code of Conduct](CODE_OF_CONDUCT.md), and contributions are licensed under [Apache 2.0](LICENSE).
